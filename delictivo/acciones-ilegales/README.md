# ACCIONES ILEGALES

En esta sección encontrarás las guías específicas de cada tipo de acción ilegal: requisitos, procedimiento, consecuencias legales y prohibiciones. Se irá actualizando constantemente.

{% hint style="info" %}
Antes de realizar cualquier acción, lee la [Normativa de Bandas](../principios-generales.md) — contiene las reglas generales que aplican a **todos** los eventos criminales (estructura, armamento, inferioridad numérica, curaciones, etc.).
{% endhint %}
