# ACCIONES ILEGALES

En esta sección encontrarás las guías específicas de cada tipo de acción ilegal: requisitos, procedimiento, consecuencias legales y prohibiciones. Se irá actualizando constantemente.

{% hint style="info" %}
Antes de realizar cualquier acción, lee la [Normativa Ilegal](../normativa-ilegal.md) — contiene las reglas generales que aplican a **todos** los eventos criminales (inferioridad numérica, secuestros, GG, EMS, etc.). Si perteneces a una organización, consulta también la [Normativa de Organizaciones](../principios-generales.md).
{% endhint %}
